VEX 0.1.7

Extract the ZIP, then run Vex.exe.

Vex is a native C++ Windows application. Its interface and animated artwork
are embedded inside Vex.exe. Microsoft Edge WebView2 Runtime is required and
is included with Windows 10 and Windows 11.

This build includes demo accounts, seven color themes, animated navigation, and
interactive Vex artwork.

Launch Client starts an installed Minecraft Java 1.21.5 in offline mode.
Single-player works; multiplayer and Realms require Microsoft sign-in.
Vex launches through a separate game profile with custom Vex title branding.
